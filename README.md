# Personal Portfolio

A personal portfolio website built by **Ryan Otieno**, a Software Development student at Moringa School to showcase what I have to offer the 
job market. Built with HTML and CSS knowledge.

## 1. Definition of the Problem
The need for a personal portfolio is to enable people to get to know me in terms of a brief introduction, what skills I have, what projects I have
done and how to get in contact with me.
## 2. Determine the Design
- **Header:** navigation links and a welcome message
- **About Me:** short bio and skills list
- **Projects:** cards arranged using CSS Grid
- **Contact:** email link
- Colors: dark green with an orange accent. The layout adjusts for phones.

## 3. Develop Code
```
Personal-Portfolio-2/
├── index.html
├── style.css
└── README.md
```
- Semantic HTML tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS variables for colors, BEM-style class names, comments for each section
- CSS Grid for the projects section, Flexbox for the navigation and About section

## 4. Test and Refine
- Opened the page in the browser and checked that all links work
- Resized the window to check the mobile layout
- Checked the HTML with the W3C validator (https://validator.w3.org)

## 5. Document and Maintain
To update the site, edit the text in `index.html` (replace the placeholder projects and email) and the colors at the top of `style.css`.

## How to run
Open `index.html` in your browser, or use the Live Server extension in VS Code.
